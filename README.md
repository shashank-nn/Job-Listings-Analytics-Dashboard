# Job Listings Analytics Dashboard

## Project Overview

A complete Python data analytics project that collects job listing
data through web scraping, cleans and preprocesses the data,
performs exploratory data analysis and presents insights through
an interactive Streamlit dashboard.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Plotly
- Streamlit

## Features

- Web scraping
- Data cleaning
- Missing value handling
- Duplicate removal
- Feature engineering
- Job categorization
- Job-level classification
- Label Encoding
- One-Hot Encoding
- Exploratory Data Analysis
- Statistical analysis
- Interactive dashboard
- Dataset download

## How to Run

Install dependencies:

    pip install -r requirements.txt

Run the dashboard:

    streamlit run app.py

## Data Source

Real Python Fake Jobs practice website.
